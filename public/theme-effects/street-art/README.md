Street Art assets
=================

- `concrete.webp`, `spray-cluster.webp`, `spray-can.webp`: generated specifically for StreamersCenter using the built-in image generation tool. No interface, slot imagery or text is baked into the background. Spray-can images retain alpha transparency.
- `metal-grain.svg`: lightweight shared procedural grain and worn-edge texture.
- All three raster assets together are approximately 1.06 MB. They are static and reused between widget instances.
- Header lettering uses the unmodified Permanent Marker font from [Google Fonts](https://github.com/google/fonts/tree/main/apache/permanentmarker), bundled in `public/fonts/street-art/` with its Apache 2.0 license. Copyright and font metadata remain embedded in the font.
