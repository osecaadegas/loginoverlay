# Solverde assets

`solverde-pt-branco-verde.svg` is the original logo obtained from the brand's public asset:
https://solverde.pt/library/new-assets/solverde-pt-branco-verde.svg

`logo.svg` retains its paths and colours with an artwork-sized viewBox, removing the original export's empty margins.

`brand-slide.svg` uses the same official emblem and letter paths, arranged vertically on an ivory surface. White lettering becomes dark emerald for contrast on ivory; the brand green remains intact. The cropped sun engraving and fine geometric texture are separate SVG elements.

The slideshow uses this slide only when no user media is configured. Uploaded images and videos replace it through the existing slideshow pipeline.
