STREAMERSCENTER SLOT CAPTURE - CHROME / EDGE

1. Extraia completamente este ficheiro ZIP.
2. Abra chrome://extensions no Chrome ou edge://extensions no Edge.
3. Ative o Modo de programador.
4. Clique em "Carregar expandida" / "Load unpacked".
5. Selecione esta pasta, que contém manifest.json.
6. Volte a https://streamerscenter.com/slot-capture e recarregue a página.

O navegador não permite que o site instale diretamente uma extensão fora da
Chrome Web Store ou Microsoft Edge Add-ons. Não execute ficheiros desconhecidos
e confirme que o nome apresentado é "Streamers Center Slot Capture".
