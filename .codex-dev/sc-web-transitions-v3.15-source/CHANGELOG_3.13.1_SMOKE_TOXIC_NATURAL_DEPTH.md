# SC Web Transitions v3.13.1 — Smoke Toxic Natural Depth RC1

Base: v3.13.0 Smoke Toxic Volumetric.

## Focus
Push **Smoke** and **Toxic Cloud** further toward a more realistic and natural feel, with less obviously shaped clouds, stronger toxic glow, and more dramatic depth / parallax.

## What changed
- Rebuilt the puff textures into more **organic asymmetrical plume sprites**.
- Reduced the obvious rounded cloud silhouette and added more breakup / wispy irregularity.
- Increased pseudo-3D **depth and parallax** using stronger layered offsets, wind drift, swirl motion and per-layer variation.
- Added secondary offset plume cards to break up the main form and make the cloud feel more natural.
- Increased **toxic internal glow** and lighting richness for a more vivid poisonous look.
- Kept normal smoke more realistic and restrained instead of overly glowy.
- Preserved the existing OBS-safe concealment / handoff logic.

## Intended result
Smoke should now look less like a stylized cloud shape and more like a natural drifting plume, while Toxic Cloud should feel deeper, richer and more glowing without losing coverage behavior.
