# Money IN Rain Rework — quick setup

1. Close the previous SC Web Transitions build.
2. Launch `SC_Web_Transitions_v3.11.1_Money_IN_Rain_Rework_RC1.exe` on Windows.
3. Connect OBS and realign sources if required.
4. Select **Money CGI Ultra**.
5. Test `GPU transition rendering engine = WebGL2 3D` first, then `Canvas2D compatibility`.
6. Trigger **Money IN** and confirm the notes rain down over time and pile into the webcam silhouette before the reveal.
7. If OBS shows artifacts, switch to 2D mode and save settings.
