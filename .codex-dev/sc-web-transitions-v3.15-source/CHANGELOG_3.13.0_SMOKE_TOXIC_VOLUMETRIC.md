# SC Web Transitions v3.13.0 — Smoke Toxic Volumetric RC1

Base: v3.12.1 Ice Sparkle Crack Flash.

## Focus
Upgrade **Smoke** and **Toxic Cloud** so they feel more premium and 3D, while preserving the existing OBS-safe concealment logic.

## What changed
- Reworked cloud rendering into a **multi-layer volumetric billboard system** for a stronger pseudo-3D look.
- Added per-cloud **yaw, pitch, roll, stretch, light, rim, and inner glow** attributes.
- Each cloud now renders as several stacked cloud cards, creating a thicker **3D smoke volume** instead of a flatter 2D puff.
- Added soft **self-shadowing** and **rim highlights** so the smoke reads with more depth.
- Toxic clouds now have stronger **internal green glow** for a richer poisonous feel.
- Preserved the gas coverage / handoff path used for OBS camera concealment.
- Preserved all Money CGI Ultra and Ice Shatter premium upgrades from earlier builds.

## Intended result
Smoke and Toxic Cloud should now feel fuller, deeper and more cinematic, with visible layered cloud volume rather than simple flat sprites.
