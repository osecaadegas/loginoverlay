# Ice Shatter Luxury Spin — quick setup

1. Close the previous SC Web Transitions build.
2. Launch `SC_Web_Transitions_v3.12.0_Ice_Shatter_Luxury_Spin_RC1.exe`.
3. Connect OBS and realign sources if needed.
4. Select **Ice Shatter Ultra**.
5. Test **Ice OUT** and **Ice IN** in both `WebGL2 3D` and `Canvas2D compatibility`.
6. Look for much clearer shard rotation, stronger airborne motion and a more premium breakup.
