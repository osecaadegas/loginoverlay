# Money IN Premium Polish — quick setup

1. Close the previous SC Web Transitions build.
2. Launch `SC_Web_Transitions_v3.11.2_Money_IN_Premium_Polish_RC1.exe`.
3. Connect OBS and realign sources if needed.
4. Select **Money CGI Ultra**.
5. Test **Money IN** in both `WebGL2 3D` and `Canvas2D compatibility`.
6. Check for denser foreground notes, heavier settling and a smoother reveal.
