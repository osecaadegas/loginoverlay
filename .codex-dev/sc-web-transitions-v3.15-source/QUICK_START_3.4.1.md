# SC Web Transitions v3.4.1 VFX Polish — Private Test

1. Close the existing SC Web Transitions process entirely.
2. Keep a backup of your previous working EXE.
3. Start `SC_Web_Transitions_v3.4.1_VFX_Polish_RC.exe` and connect OBS WebSocket.
4. Click **Install / realign camera renderer** so the OBS Browser Source loads the updated embedded VFX module. Verify the renderer version `3.4.1-vfx-polish-rc1`.
5. Test the eight new effects individually in OUT and IN while NOT live. Use real Program capture to inspect camera concealment, moving subjects, material quality, breakup choreography and residual alpha.
6. If any effect leaves the wrong camera state or stuck FX, use Recover Camera; return to the previous version if necessary.
