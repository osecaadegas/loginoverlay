SC Golden Sheep Money CGI 3D assets
==================================

Import each of the four .glb files in Blender using File > Import > glTF 2.0.
These models are 3D bent paper surfaces textured with the ORIGINAL bill.png artwork.
The collection GLB contains all four poses laid out side-by-side.
The golden_sheep_paper_normal.png and golden_sheep_paper_roughness.png maps
are supplementary PBR detail maps.

Note: the SC app does not depend on Blender being installed.
The app uses an animated WebGL2 deformable paper shader, not pre-rendered 3D footage.
The GLB files are Blender-editable source materials for further authored artistry.
