# SC Premium VFX — Editable GLB art kit

Blender is not installed in the build environment, but these `.glb` files can be imported into Blender or another glTF-compatible 3D editor.

**Blender:** File → Import → glTF 2.0 (.glb/.gltf). Choose `SC_Premium_VFX_Asset_Collection.glb` to load all fifteen meshes, or individual category hero files.

Included geometry: 8 asymmetrical prismatic crystal meshes, 4 curved double-sided petals and 3 curved double-sided dark feathers. The normal maps are texture source assets and may need manual connection to Blender's Principled BSDF if not imported as linked normal maps.

**Materials:** `crystal_albedo.png`, `petal_albedo.png`, `feather_albedo.png` plus similarly named normal source maps. Geometry normals and UVs are in the GLB.

**Important:** The Windows application's built-in geometry comes from `premium-vfx-meshes.js`, generated by `tools/generate_premium_assets.py`. Editing a GLB in Blender does not automatically update the app. To integrate revised hand-authored models, a future importer/converter must regenerate the corresponding WebGL vertex streams. The supplied offline generator is the current geometry source of truth.

All assets are original programmatically generated starter art, intended for further professional hand-authored polish.
