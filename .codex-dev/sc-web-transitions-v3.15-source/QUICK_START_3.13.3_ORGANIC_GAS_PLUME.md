# Quick test guide

1. Keep v3.13.2 as a rollback, close it, and launch the v3.13.3 Windows EXE.
2. Connect OBS and test off-stream. Choose **Black Smoke**, then **Toxic Cloud**.
3. Trigger **OUT**. You should see scattered plumes emerge from below, rise and merge, rather than a full cloud wall appearing suddenly. The camera only hides after verified full cover.
4. Watch the release: the thick smoke softens/disappears first, leaving smaller drifting wisps; the effect ends transparent.
5. Repeat **IN**, then re-test Money OUT/IN and Ice OUT/IN. Use the 2D quality settings as necessary if OBS cannot keep up.
