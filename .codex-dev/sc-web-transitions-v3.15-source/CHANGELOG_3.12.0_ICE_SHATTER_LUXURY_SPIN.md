# SC Web Transitions v3.12.0 — Ice Shatter Luxury Spin RC1

Base: v3.11.3 Money IN Luxury Pass.

## Focus
Bring **Ice Shatter** up to the same premium level, with much more visible shard rotation and more cinematic blast-away motion.

## What changed
- Increased shard **rotation intensity** so pieces visibly spin in the air as they shatter away.
- Added per-shard **spin boost**, **lift**, and **wobble** parameters for a more premium airborne feel.
- Improved the 2D fallback blast path with stronger spin, nicer upward arc, and livelier breakup motion.
- Upgraded the **WebGL2 3D Ice Shatter Ultra** vertex motion so shards rotate more aggressively across multiple axes in flight.
- Preserved the existing keyed frost growth, crack buildup, and silhouette-safe visibility handoff.
- Preserved all Money CGI Ultra improvements from previous builds.

## Intended result
Ice shards should now feel more physical and dramatic, rotating clearly as they fly outward instead of just sliding away with only subtle twist.
