Setup & Troubleshooting

Everything runs on your own Windows PC.

One executable, one shortcut

Run SC Web Transitions.exe once. It copies itself into your Windows user profile, creates a desktop shortcut and starts. Next time, open it from the same desktop icon. Python is not required.

OBS setup

In OBS 28+, go to Tools → WebSocket Server Settings, enable the server, use port 4455, copy the password and connect on the OBS page here. Select the webcam that is directly present in your active scene, and click Install.

Correct silhouette alignment

Add Chroma Key / background removal directly to the webcam source in OBS, before using it. The transition uses the alpha silhouette and copies the webcam's OBS transform. If the screenshot has no foreground mask, the renderer will show an error rather than animate a rectangular image.

Money Burst v2 & additional effects

Money OUT drops different-sized golden sheep bills over the live webcam; only after coverage does OBS hide the real camera. Bills fall, and one oversized bill flies toward the lens and slides down.
